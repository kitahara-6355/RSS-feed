# RSS学習ログの運用

スプレッドシート「RSS学習ログ」は Apps Script（`gws/apps-script/`）で毎日新着RSSを取り込み、
興味キーワードで分類している。このスキルは、そのシートを読んで手入れするための手順。

## シート

- **フィード**: 有効(チェック) / 名前 / URL / カテゴリ / 用途（学習・SNS監視など） / 重み / 最終取得 / 状態
- **記事**: ID / 取得日時 / 公開日時 / ソース / タイトル / URL / 概要 / タグ / 関連度 / AI要約 / 興味度 / 重要度 / ステータス / 画像
- **興味キーワード**: キーワード / 重み / 分類 / 由来（旧版プロファイル・学習・手入力）
- **設定**: 要約方式・関連度しきい値・1フィードあたり件数・1回のAI処理上限・Geminiモデル・取得時刻
- **ログ**: 実行ごとの結果

## よくある依頼

### フィードを追加する
1. サイトのRSS／AtomのURLを確かめる（note は `https://note.com/<id>/rss`、YouTube は
   `https://www.youtube.com/feeds/videos.xml?channel_id=<id>`）。
2. フィード シートの最終行に `TRUE, 名前, URL, カテゴリ, 学習` を追加する。重みは空でよい。
3. 次回の取得で 状態 が「OK（新着n件）」になるのを確認する。「エラー」ならURLを見直す。

### 今週の新着を振り返る
記事 シートを 取得日時 が直近7日の行に絞り、関連度の高い順に10件、タイトル・ソース・AI要約（なければ概要）を
並べて報告する。興味度が未入力のものは評価を付けるよう促す。

### 興味の調整
- 増やしたい話題: 興味キーワード に `キーワード, 重み(1〜6), 分類, 手入力` を追加する。
- 由来が「学習」の行は毎週の学習で上書きされる。固定したいときは由来を「手入力」に変える。

### SNS監視に使う
SNS自動管理ダッシュボードで競合や業界の新着を見るときは、用途を「SNS監視」にしたフィードを
`Store.feeds('SNS監視')` で取り出し、`RssCore.fetchFeeds()` に渡す。学習ログの記事シートには混ぜない。

## してはいけないこと

- 課金が有効なGoogle CloudプロジェクトのAPIキーを `GEMINI_API_KEY` に入れない。
- APIキーをシートやファイルに書かない（スクリプトプロパティのみ）。
- 取得した記事をSNSへ自動投稿しない（投稿は人が確認してから）。
