# RSS to Notion: AI-Powered Learning Log

指定した複数のRSSフィードから新しい記事を自動で取得し、Google Gemini AIで内容を分析して関連タグを付与し、Notionデータベースに学習ログとして蓄積するシステムです。  
GitHub Actionsにより6時間ごとに自動実行されるため、PCの稼働状態に関係なく、24時間365日自律的に情報収集・整理が行われます。

---

## 主な機能

- **複数RSSフィードの監視**  
  `src/config.py` のURLリストに基づき記事を収集します（最新20件を取得）。

- **AIによる自動タグ付け**  
  Geminiが記事のタイトル・概要を解析し、最適なカテゴリタグを自動生成。

- **興味プロファイルに基づくフィルタリング**  
  ユーザーの評価を学習し、関連性の低い記事は自動で除外。

- **Notionへの自動蓄積**  
  指定データベースに記事を自動追加。重複登録も防止。

- **代表画像の添付**  
  記事に含まれる代表的な画像を1枚選択し、Notionに自動添付。

- **日本語要約の生成**  
  英語記事の場合はGeminiにより日本語要約を生成し保存。

- **優先度スコア計算**  
  興味度・重要度を基に外部スクリプトで数値スコアを算出。

- **エラーロギング**  
  AI処理や通信エラーを `logs/` にJSON形式で保存。

- **完全自動実行**  
  GitHub Actionsにより6時間ごとに自動実行。手動実行も可能。

## セットアップ手順

### ステップ1: Notionの準備

1. **データベース作成**  
   - 「テーブル - フルページ」を作成し、以下のプロパティを追加:

   | プロパティ名 | 種類 (Type) |
   | --- | --- |
   | `Title` | タイトル |
   | `URL` | URL |
   | `Status` | ステータス |
   | `Source` | マルチセレクト |
   | `Author` | リッチテキスト |
   | `Publication Date` | 日付 |
   | `Tags` | マルチセレクト |

   - `Status` には **`未読`** と **`あとで読む`** を必ず追加。

2. **評価用プロパティの追加**  
   - 学習機能を強化するため、以下も追加:

   | プロパティ名 | 種類 | 説明 |
   | --- | --- | --- |
   | `興味度` | 数値 | 記事への興味 (1〜5) |
   | `重要度` | 数値 | 学習/仕事への重要性 (1〜5) |
   | `優先度スコア` | 数値 | スクリプトで自動計算 |
   | `日本語要約` | テキスト | 英語記事をAIが要約 |

   ※ `優先度スコア` は **数値** で作成し、数式ではありません。

3. **Notionインテグレーション作成**  
   - [Notion Integrations](https://www.notion.so/my-integrations) から新規作成し、`secret_...` または `ntn_...` のトークンをコピー。

4. **データベース連携**  
   - DB右上「・・・」>「コネクトを追加」でインテグレーションを招待。

5. **データベースID取得**  
   - URL `https://www.notion.so/DATABASE_ID?v=...` から32文字のIDをコピー。

---

### ステップ2: Google AI (Gemini) APIキー準備

1. [Google AI Studio](https://aistudio.google.com/) にアクセス。  
2. 「Get API key」>「Create API key in new project」を選択。  
3. 表示されたAPIキーをコピー。

---

### ステップ3: GitHub Secretsの設定

リポジトリの **Settings > Secrets and variables > Actions** で以下を追加:

- `NOTION_TOKEN` → Notion APIキー  
- `NOTION_DATABASE_ID` → データベースID  
- `GOOGLE_API_KEY` → Gemini APIキー  
- `NOTION_SUGGESTIONS_PAGE_ID` → 推薦リスト用ページID

## 使い方とカスタマイズ

### 自動実行
- デフォルトで6時間ごとに新着記事を収集しNotionに登録。

### 手動実行
- **エンリッチ機能**: タグ未設定記事にAIでタグ付与  
- **優先度計算**: 興味度・重要度からスコアを一括算出  

### 興味学習
- 週1回、評価データを学習し `user_profile.json` を更新。  
- 精度向上や新規RSS推薦に活用。

### 新規RSS推薦
- 月1回、AIが新しいフィード候補を探索し、Notionページに追記。

## カスタマイズポイント

- **フィルタリング閾値調整**: `src/config.py` → `FILTERING_THRESHOLD`
