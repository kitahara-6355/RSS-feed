# RSS to Notion: 自動学習ログシステム

指定した複数のRSSフィードから新しい記事を自動で取得し、キーワードに基づいてタグ付けを行い、Notionデータベースに学習ログとして蓄積するシステムです。

このシステムはGitHub Actions上で定期的に（6時間ごとに）実行されるため、一度設定すれば、あなたのPCの電源状態に関わらず、24時間365日、自動で情報収集と整理を続けてくれます。

## 主な機能
- **複数RSSフィードの監視**: 設定ファイル内のURLリストに基づいて、複数のサイトを巡回します。
- **Notionへの自動蓄積**: 新しい記事を、指定したNotionデータベースに自動で追加します。
- **重複登録の防止**: Notionデータベース内に同じURLの記事がすでに存在する場合、重複して登録されるのを防ぎます。
- **キーワードによる自動タグ付け**: 記事のタイトルや概要に含まれるキーワードを基に、自動でタグを付与します（例：「AI」「Python」「Business」など）。
- **完全自動実行**: GitHub Actionsにより、6時間ごとに自動で実行されます。手動での実行も可能です。

## 必要なもの
- GitHubアカウント
- Notionアカウント
- Python 3.7以上（スクリプトをローカルでカスタマイズする場合にのみ必要）

## セットアップ手順

このシステムを動作させるには、NotionとGitHubの連携設定が必要です。

### ステップ1: Notionの準備

まず、RSS記事を保存するためのNotionデータベースと、プログラムからアクセスするためのAPIキー（インテグレーション・トークン）を準備します。

#### 1. Notionデータベースの作成
1.  Notionで新しいページを作成し、「**データベース - フルページ**」を選択します。
2.  データベースの名前を、ご自身が分かりやすい名前に設定します（例: `My RSS Learning Log`）。
3.  以下の通りに、データベースのプロパティ（列）を設定・変更してください。**プロパティ名と種類は、スクリプトが正しく動作するために、完全に一致させる必要があります。**

| プロパティ名 | 種類 (Type)  |
| :----------- | :----------- |
| `Title`      | `タイトル`   |
| `URL`        | `URL`        |
| `Status`     | `セレクト`   |
| `Source`     | `セレクト`   |
| `Author`     | `リッチテキスト` |
| `Published`  | `日付`       |
| `Tags`       | `マルチセレクト` |

#### 2. Notionインテグレーションの作成とAPIキーの取得
1.  [Notionのインテグレーション管理ページ](https://www.notion.so/my-integrations)にアクセスします。
2.  「**+ 新しいインテグレーション**」ボタンを押します。
3.  名前（例: `GitHub RSS Bot`）を入力し、関連付けられたワークスペースを選択して「送信」します。
4.  作成が完了すると、「Secrets」というセクションに**インテグレーション・トークン**が表示されます。「**Internal Integration Token**」と書かれたもので、`secret_...`という形式です。
5.  「**Show**」をクリックしてから、このトークンをコピーしてください。**これはパスワードと同じくらい重要なので、他人に教えないでください。** このトークンが、後のステップで `NOTION_TOKEN` になります。

#### 3. データベースとインテグレーションの連携
1.  ステップ1で作成したNotionデータベースに戻ります。
2.  右上の「・・・」メニューから、「**+ コネクトの追加**」を選択します。
3.  検索欄に、ステップ2で作成したインテグレーションの名前（例: `GitHub RSS Bot`）を入力し、表示されたものを選択して連携を許可します。
4.  これで、あなたのスクリプト（インテグレーション経由）が、このデータベースを編集する権限を持ちました。

#### 4. データベースIDの取得
1.  ブラウザでNotionデータベースを開いているとき、URLは以下のようになっています。
    `https://www.notion.so/YOUR_WORKSPACE/DATABASE_ID?v=...`
2.  この `DATABASE_ID` の部分（32文字の英数字）をコピーしてください。これが、後のステップで `NOTION_DATABASE_ID` になります。

### ステップ2: GitHub Secretsの設定

次に、取得したNotionの情報を、安全な形でGitHubに設定します。

1.  このGitHubリポジトリの「**Settings**」タブ > 「**Secrets and variables**」 > 「**Actions**」に移動します。
2.  「**New repository secret**」ボタンを押し、以下の**2つ**のSecretを一つずつ作成します。

    - **Secret 1: `NOTION_TOKEN`**
        - **Name**: `NOTION_TOKEN`
        - **Secret**: ステップ1-2で取得した**インテグレーション・トークン**（`secret_...`）を貼り付けます。

    - **Secret 2: `NOTION_DATABASE_ID`**
        - **Name**: `NOTION_DATABASE_ID`
        - **Secret**: ステップ1-4で取得した**データベースID**を貼り付けます。

## 使い方とカスタマイズ

### 実行
上記の設定が完了すれば、**自動的に6時間ごとにスクリプトが実行され、新しい記事がNotionデータベースに追加されます。**

すぐに動作を確認したい場合は、手動で実行することも可能です。
1.  リポジトリの「**Actions**」タブを開きます。
2.  左側の「**RSS to Notion Sync**」ワークフローを選択します。
3.  「**Run workflow**」ボタンを押します。

### カスタマイズ

#### 監視するRSSフィードの変更
- `src/main.py`ファイルを開き、`RSS_FEEDS`という辞書を編集することで、監視対象のURLを変更・追加・削除できます。

#### 自動タグ付けルールの変更
- `src/main.py`ファイルを開き、`TAG_RULES`という辞書を編集することで、キーワードとタグの対応関係を自由に変更できます。
